<h1>Make an Email Signature from Scratch</h1>
If you want to try your hand at a bit of HTML in a practical way without having to build a website, an email signature is a great way to start. There are plenty of free tools that you can build a decent email signature like Hubspots: https://www.hubspot.com/email-signature-generator, so doing it yourself is not necessary. It can be a fun way to play with HTML in a way that other people might see without having to worry about hosting a website.

<h2>Configuration Steps</h2>

<h3>Step 1: Coming Soon!</h3>

Save an HTML file on your computer. There are programs you can download that make the HTML easier to view by assigning colors for certain functions. You can also use Notepad on Windows, you just won't have the fancy colors. On Chromebook, you can use a program called txt in the same way, except once you save the file as a .html, the colors pop up to assist your coding. You won't need more than a notepad program to edit a txt file for this though. 
- You can name the file anything you want as long as you save it as a .html file. I will use index-1.html. This way, if you like your first draft, you can copy and duplicate it as index-2.html and make changes without losing the code for this first one.
- When you save the document, you may have to click on "Save File Type" and choose "All Files" to be able to type .html.
